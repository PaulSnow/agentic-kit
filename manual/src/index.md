# Agentic Coding Starter

Starter is a working template for building software with coding agents. It gives a project a written brief, a phased plan, reusable skills, independent product review, and executable checks. The operator controls consequential decisions and judges the resulting product.

Wolf McNally created and maintains Starter. His [Encyclopedia of Agentic Coding Patterns](https://aipatternbook.com/) explains the broader vocabulary and patterns behind agentic development.

Start with [Get Started](getting_started.md) to create a project. Use [Run a Phase](workflow.md) for the everyday development loop. The [skill reference](skills.md) and [command reference](tools.md) help when you know the task you want to perform.

This manual describes the methodology as it works now. The repository's briefs and policies retain the full authority and detail. They are available in the [source repository](https://github.com/wolfmcnally/agentic-coding-starter); operational records are outside this published manual.

```admonish tip title="Keep the project’s manual about its product"
A project derived from Starter documents its own users, features, setup, and operation. A brief acknowledgment and a link to this manual are enough to explain that it uses the Starter methodology.
```
